# quale-conviene

A tool to compare products in the same category and figure out **which one is the best deal**.

You provide a category (e.g. olive oil, baby diapers, dishwasher tablets, smartphones in a price range) and the app surfaces the available options side-by-side: price per unit, headline specs, brand, retailer, expiration of the offer when relevant. The output ranks them so it's immediately obvious **quale conviene** — which one wins on cost-effectiveness for your needs.
